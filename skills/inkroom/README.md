# InkRoom image creation Skill

[Official website](https://inkroom.ai/) · [Skill setup and documentation](https://inkroom.ai/skill-server) · [MCP documentation](https://inkroom.ai/mcp-server)

Client 1.0.8 queries public models, InkRoom sales prices, help and published prompts without a Key. Generate, edit and upscale images with the user’s InkRoom account and Key; private receipts and previews remain authenticated. The Skill package is free; media generation uses the prices and cost previews returned by InkRoom. Installing it does not grant free generation.

Read [SKILL.md](SKILL.md) for installation, authorization, previews and recovery.
